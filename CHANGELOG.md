# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] — Unreleased

### Added

- **`minimal` template** — Lightweight starter with Next.js 16, React 19, TypeScript strict, Tailwind CSS 4, shadcn/ui patterns
- **`with-auth` template** — Authentication-ready with Clerk, MongoDB/Mongoose, Redis, Resend
- **`api-only` template** — Backend service with Zod validation and MongoDB
- **`with-ecommerce` template** — Draft structure for full e-commerce stack (Clerk, Razorpay, Cloudinary, Resend, Tiptap)
- **OpenCode agent system** — 11 agents (build, plan, coder, tester, code-reviewer, etc.) configured via `opencode.jsonc`
- **`use-template.ps1` script** — PowerShell script for template deployment
- **CLI tool** — `npx create-nextjs-template` scaffolding (in development)
- **GitHub workflows** — CI, release, publish, stale issue management
- **Community files** — CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, LICENSE, issue/PR templates
- **`AGENTS.md`** — Agent architecture documentation and conventions
